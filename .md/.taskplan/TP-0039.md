**Referência visual:** não se aplica.

1. TDD: testes da Seção 2 primeiro.
2. `formato.ts`: `paraItemTarefa(linha)` → `{id, nome, periodicidade, atribuido, arquivada}`: `tipo='dias'` → `{tipo, dias: diasDaMascara(dias_semana)}`; `semanal_flexivel` → `{tipo}`; `atribuido` = `MembroResumo` ou `null` (Qualquer um). Nenhuma conversão de máscara à mão.

4. Rota: valida a query (`filtro` ausente ou `'arquivadas'`; outro valor → 400), resolve o ator **só** pela sessão (ADR-004) e chama o caso de uso.

Proposta: `{erro:'sem_permissao'}` e `{erro:'nao_encontrada'}` no `EsquemaErro`, com mensagem pt-BR neutra, valendo para TP-0040 a TP-0043. Confirmar com o Coordenador, ou USAR o código de 403 se um endpoint anterior já tiver fixado um.
