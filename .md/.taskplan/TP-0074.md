## 3. Plano de validação de segurança
- CA-02.2: a tela não distingue e-mail inexistente de senha errada (só mostra o texto do 401).
- Senha nunca em `localStorage`, URL, log ou `console`; após erro, o campo senha é limpo.
- Sessão só pelo cookie `HttpOnly` que a API define (TP-0029): o front não guarda token. `credentials: 'same-origin'` vem do cliente (TP-0063).
- Sem domínio literal (G-01); textos de `textos/` (G-24).
