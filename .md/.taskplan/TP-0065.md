Service worker (`generateSW`, `registerType: 'autoUpdate'`, `injectRegister: null`): `globPatterns` só do shell (`**/*.{html,js,css,woff2,svg,png,webmanifest}`), `navigateFallback: '/index.html'` com `navigateFallbackDenylist: [/^\/api\//]`; um único `runtimeCaching` para `/^\/api\//` com `handler: 'NetworkOnly'` e um plugin `handlerDidError` que devolve `503`, `Content-Type: application/json`, `{"erro":"sem_conexao","mensagem":…}`. A função do plugin é serializada pelo Workbox (não enxerga imports): o corpo é gerado em `configuracao.ts` com o texto de `textos/` embutido como literal. ## 2. Plano de teste
- `test/pwa/configuracao.test.ts`: o objeto exportado tem exatamente uma regra de `runtimeCaching`, para `/api/`, com `NetworkOnly`; nenhuma outra estratégia; `globPatterns` sem `json` e sem `api`; `/api/hoje` está no `navigateFallbackDenylist`; manifest com `display`, `start_url`, `scope`, `id` e ícones 192/512/maskable com caminho relativo; `handlerDidError` devolve 503 cujo corpo passa no `EsquemaErro` e tem `erro: 'sem_conexao'`.
- Pós-build (`pnpm --filter @tdc/pwa build`): `dist/sw.js` não lista nenhum `/api/` no precache; `dist/manifest.webmanifest` e `dist/sw.js` sem `http(s)://` de domínio; os 4 PNG existem com o tamanho declarado.
- `test/pwa/deteccao.test.ts`: tabela com os UAs do `telas.json` (iPhone e Android), iPad iPadOS (UA de Mac + toque), Mac Safari, Windows Edge → `computador`; `standalone` por `navigator.standalone` e por `matchMedia`; UA vazio → `computador`.
- Manual (registrar em `## 4`): `build` + `preview`, Chrome DevTools > Application > Manifest sem erros de instalabilidade; Network offline, recarregar: o shell abre e `GET /api/situacao` responde 503 `sem_conexao`; Application > Cache Storage sem nenhuma entrada `/api/`.
Comando: `pnpm --filter @tdc/pwa exec vitest run test/pwa`.

## 3. Plano de validação de segurança
- G-25/ADR-005: nenhuma rota de dados em cache (teste de configuração e Cache Storage).
- G-01/ADR-006 item 2: manifest, service worker e ícones só com caminho relativo; conferir `dist/` com busca por `vercel.app` e `http`.
