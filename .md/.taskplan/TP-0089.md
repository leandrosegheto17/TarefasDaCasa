## 3. Plano de validação de segurança
- CONVENCOES §8: o formulário valida com o mesmo esquema do contrato que a API usa (nome 1 a 60, dias ≥ 1 sem repetição, `tipo` da união); `maxlength` é só ajuda.
- ADR-004/G-16: o id em "Quem" é o atribuído, nunca o autor; o autor vem da sessão no servidor; 403 da API vale mesmo com a `SoResponsavel`.
- G-19: `PATCH`/`POST` com `Content-Type: application/json` pelo `requisitar`. ADR-005: sem otimismo, só navega com a resposta 2xx.
- Mensagem do servidor só passa por `EsquemaErro` + `erros-formulario.ts`, com textos de `textos/` (G-24); G-12 (a tela não calcula vigência), G-26, G-28.
