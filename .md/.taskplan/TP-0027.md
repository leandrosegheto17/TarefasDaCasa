## 2. Plano de teste
Integração contra o Postgres local, com `criarApp(config).request(...)`, fábricas que apagam o que criam e relógio fixo. Cada resposta passa por `RespostaSituacao.parse`.
- Sem família → `{familiaExiste: false, sessao: null}` (igual a `situacao-primeiro-uso.json`, exceto a versão).
- Com família e sem cookie → `familiaExiste: true, sessao: null`.
- Sessão de Criança → `membro.papel = crianca`, sem `precisaCriarAcesso`.
- Responsável sem credencial → `precisaCriarAcesso: true`. Responsável com credencial → campo ausente.
- Host = origem → sem `ambienteTeste`. Host de preview (`x-git-main.vercel.app` vindo da config de teste) → `ambienteTeste: true`. Mesma origem com maiúsculas → ausente.
- Cookie com token inexistente, revogado ou vencido → 200 sem sessão (conforme o PENDENTE). Nunca 500.
- Unitário da comparação de host, com casos adversariais: porta diferente, sufixo `origem.evil.com`, host vazio.
- Comando: `pnpm --filter @tdc/api test:integracao -- situacao`.
